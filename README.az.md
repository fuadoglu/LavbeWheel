## 🎯 Razılaşdırılmış məhsul

- **Lavbe.com:** ad/rəqəm/bəli-xeyr çarxları, çəkili seçim və komanda bölgüsü.
- **Sosial oyunlar:** butulka, doğruluq/cəsarət, cütlük və dost qrupları; açıq seksual məzmun yoxdur.
- **UX:** mobil, planşet və kompüter; yüksək sürət, axıcı animasiya, hər alətə uyğun stil, gecə/gündüz.
- **Adlar:** sahəyə uyğun şrift; fiziki oxunaqlılıq həddində qısaltma və tam adı ayrıca görmək.
- **Hesabat:** nəticə tarixçəsi, seçilmə sayı, faiz, raundlar və CSV.
- **Paylaşma:** adlar və ayarlarla sabit çarx nüsxəsi; ayrıca silmə açarı və müddət.
- **110 planlaşdırılmış dil:** cihaz dili və ölkə siqnalı ilə seçim, əl ilə dəyişmə, RTL; hər dil üçün keyfiyyət yoxlaması.
- **PWA:** ana ekrana əlavə etmə, əvvəl yüklənmiş əsas alətlərin offline işləməsi.
- **Monetizasiya:** istifadəyə mane olmayan reklam; razılığa uyğun GA4 və GTM.
- **Yerləşdirmə:** statik Astro/TypeScript + PHP/MySQL; shared hosting uyğunluğu.

## ✅ Buraxılış prinsipi

MVP olmayacaq. İctimai buraxılış bütün məcburi funksiyalar və qəbul yoxlamaları tamamlandıqdan sonra edilir. Daxili icra mərhələləri yarımçıq məhsulu yayımlamaq icazəsi deyil. Təhlükəsizlik və xarici xidmətlərlə uyğunluq üçün texniki qulluq davam edir.

## 🤖 Codex üçün

Normativ texniki sənədlər dəqiqlik üçün ingiliscədir. Kodlamaya [AGENTS.md](AGENTS.md) və [icra planından](docs/15-IMPLEMENTATION.md) başlayın. `python3 scripts/validate_docs.py` sənəd paketini yoxlayır; tətbiqin hazır olduğunu təsdiqləmir.

Əsas xarici buraxılış məlumatları: operatorun hüquqi rekvizitləri, domain/hosting girişi, tərcümə və oyun məzmunu rəyləri, CMP/Google hesabları və reklam təsdiqi. Bu məlumatlar uydurulmamalıdır.
