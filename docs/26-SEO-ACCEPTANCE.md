Evidence manifest fields: requirementId, commit/buildId, method, scope (all-routes/sample/manual), artifact, reviewer, result, limitations. Any sample test must not be claimed all-route. Existing SEO-01 remains mandatory. No green documentation check can satisfy these application gates.

## Local-market research record

For each locale/route: native primary intent, synonyms, source URL/tool, query location/device/date, observed result types, competitor URLs, differentiation note, proposed title/H1/description and reviewer/status. Volume/difficulty optional null values with named source and timestamp if supplied. Native linguistic review can validate obvious intent without paid tooling, but it cannot be misrepresented as measured keyword volume. Resolve competing own pages before publishing.

## Postlaunch observations (not prelaunch pass claims)

Field CWV, actual index coverage, search clicks/CTR and revenue require live data. Set baselines only once data exists. Review weekly, aggregate by route/locale/device and annotate changes. No arbitrary 'all pages indexed in 7 days' promise. Technical regressions trigger rollback; slow acquisition triggers research/content/distribution work, not fake freshness or new thin pages.
