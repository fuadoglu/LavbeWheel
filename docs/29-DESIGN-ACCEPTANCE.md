# Visual craft and UX acceptance

Quality target: distinctive, contemporary and polished enough to aspire to top design showcases. No award affiliation or award guarantee. Judging remains external and subjective; engineering and owner acceptance use the evidence below.

| ID | Gate |
|---|---|
| DES-01 | Original concept visible in classic, bottle and social game; no copied competitor assets |
| DES-02 | High-fidelity phone/tablet/desktop + light/dark screen set; final brand/app-icon deliverables |
| DES-03 | Complete component state gallery; no decorative-only unfinished controls |
| DES-04 | Typography, spacing, surfaces and foreground/sector contrast verified per theme/script |
| DES-05 | Long names, dense lists, RTL and 200% text do not break critical actions |
| DES-06 | Standard/quiet/party and reduced motion use same correct selection; actual-device frame evidence |
| DES-07 | Ad/consent placements included in visual acceptance, not added after screenshot approval |
| DES-08 | Keyboard, screen reader, touch and native install behavior reviewed; no essential hover-only UX |
| DES-09 | Real comparative task review; visual preference separate from task success/time |
| DES-10 | Owner visual review recorded with screenshots/build ID; known defects explicitly listed |

Review cycle: concept board → high-fidelity screen family → interactive selection/result moment → complete component gallery → all modes/locales → actual-device/performance/ads pass. Internal iteration is required for craft and does not authorize an incomplete public MVP.

Critical failures block release: unreadable controls, wrong landing result, missing labels, input loss, obscured CTA, keyboard trap, consent dark pattern or reduced-motion failure. Major inconsistencies also require correction before signoff. Minor subjective preferences are recorded and resolved by the owner; do not self-certify every visual as perfect.

Every evidence item includes commit/build, viewport, device/browser, theme, locale, consent/ad state and approval/reviewer. Store synthetic data only. The current schematic contact sheet remains a layout aid, not completion evidence for DES-02 or DES-10.
