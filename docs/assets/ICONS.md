# 🧩 Lavbe icon catalog

36 original SVG documentation icons, 24×24 viewBox, consistent stroke, no external assets or tracking. They may be adapted within this project. Runtime controls need translated accessible names; decorative icons must be hidden from assistive technology. These are not a licensed third-party brand pack or a final PWA app-icon export.

## Runtime usage

All 36 actions use the same local SVG grammar. Convert color to currentColor in runtime components and supply translated accessible labels. Dark/light contrast requires rendered verification. For additional platform icons use a local licensed subset and record attribution. Final brand/PWA app-icon exports remain a separate implementation deliverable.
