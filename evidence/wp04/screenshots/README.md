# WP04 screenshot evidence — initial classic screen

Generate these review artifacts with `npm run screenshots:wp04`. The script targets the local preview at `http://127.0.0.1:4322`; set `LAVBE_PREVIEW_URL` to capture a different local build.

All images use Playwright's bundled Chromium, Azerbaijani UI strings and synthetic sample names. Captured viewports are 390×844, 768×1024, 1024×768 and 1440×1000 CSS pixels. The result and history images come from one local spin; report images show three synthetic results at phone and tablet portrait widths. Settings are shown in dark mode. No production consent, ad, real-device, assistive-technology or owner-approval state is represented.

These screenshots show the implemented classic screen only. They do not close the WP04 visual acceptance gates for other tools, Arabic/RTL, long German labels, actual devices or owner review.
