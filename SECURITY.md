# 🛡️ Security policy

The application is not implemented or deployed by this documentation baseline. Do not interpret this repository as a security certification.

Do not post management tokens, admin credentials, real participant names or exploitable private payloads in public issues. Use GitHub private vulnerability reporting if the owner has enabled it. Otherwise request a private reporting channel from the repository owner without including exploit secrets; no security email address is fabricated here.

Implementation security requirements are in [privacy/security](docs/11-PRIVACY-SECURITY.md) and [operations](docs/17-OPERATIONS.md). Production launch requires an owner-selected reporting contact, incident owner and supported dependency inventory.

Reports should include affected version/route, reproduction using synthetic data, impact and suggested mitigation. No response-time or bounty commitment is established by this file.
